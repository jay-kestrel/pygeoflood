pygeoflood API reference
========================

The public surface is intentionally small — ``import pygeoflood`` exports
exactly two names: the :class:`~pygeoflood.pyGeoFlood` orchestrator and the
:class:`~pygeoflood.PGF_Config` options container. The compiled
``pygeoflood._rust`` module is private.

.. note::

   These pages are generated by Sphinx ``autodoc``, which works by
   **importing the installed package** — including the compiled
   ``pygeoflood._rust`` extension. Make sure pygeoflood is installed in the
   documenting environment (``pip install -e .`` with a Rust toolchain, or
   from a built wheel) before running ``sphinx-build``; see
   ``doc/pgfdocs-env.yml`` for the documentation environment.
